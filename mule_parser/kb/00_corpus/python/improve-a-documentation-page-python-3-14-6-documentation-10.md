# Improve a documentation page[¶](#improve-a-documentation-page)

We are always interested to hear ideas about improvements to the documentation.

You were reading “Python Frequently Asked Questions” at [https://docs.python.org/3/faq/index.html](https://docs.python.org/3/faq/index.html).  The source for that page is on
[GitHub](https://github.com/python/cpython/blob/main/Doc/faq/index.rst?plain=1).

You have a few ways to ask questions or suggest changes:

- You can start a discussion about the page on the Python discussion forum. This link will start a pre-populated topic: - [Question about page “Python Frequently Asked Questions”](https://discuss.python.org/new-topic?category=documentation&title=Question+about+page+%22Python Frequently Asked Questions%22&body=About+the+page+at+https://docs.python.org/3/faq/index.html%3A).
- You can open an issue on the Python GitHub issue tracker. This link will create a new pre-populated issue: - [Docs: problem with page “Python Frequently Asked Questions”](https://github.com/python/cpython/issues/new?template=documentation.yml&title=Docs%3A+problem+with+page+%22Python Frequently Asked Questions%22&description=The+page+at+https://docs.python.org/3/faq/index.html+has+a+problem%3A).
- You can - [edit the page on GitHub](https://github.com/python/cpython/blob/main/Doc/faq/index.rst?plain=1)to open a pull request and begin the contribution process.
