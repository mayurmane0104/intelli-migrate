# Adding Services to Your Portfolio > For the full documentation index, see: https://docs.mulesoft.com/llms.txt Your **Portfolio** is organized into catalogs: **Agents**, **MCP Servers**, **LLM Proxies**, **APIs**, and **Gateways**. Each catalog holds the services (or gateway entries) your organization registered or imported for governance, monitoring, and deployment. Services enter a catalog through automated provider discovery or manual registration. Use the add control for that type (for example, **Add API** or **Add Agent**), then select the available flow. For gateways, **Add Gateway** opens gateway creation in Anypoint Platform. Navigation labels can vary by catalog, enabled features, and release. ## Service Type Registration Options **Agents** Register by uploading an agent card or connect an agent provider scanner for discovery. **MCP Servers** Register with an MCP URL or a schema file, or connect an MCP server provider. **LLM Proxies** Register manually by creating an LLM proxy with a routing strategy that routes requests by provider or semantically. **APIs** Register with an API specification, or connect an API provider so scans import APIs into the **APIs** catalog. **Gateways** Create gateways in Anypoint Platform. In Enhanced Experience, select **Add Gateway** to open the Anypoint gateway creation flow.
