# SAP S/4HANA OData Connector 2.9

Anypoint Connector for SAP S/4HANA OData (SAP S/4HANA OData Connector) provides support for the OData APIs exposed by SAP S/4HANA Cloud and SAP S/4HANA on-premise.

The connector enables you to perform operations to:

- 
Create, get, update, and delete entities 
- 
Retrieve a single entity 
- 
Query multiple entities 
- 
Invoke a remote function 
- 
Execute batch requests that consist of multiple requests 

For software requirements and compatibility information, see the SAP S4/HANA Connector Release Notes.

## Before You Begin

To use this connector, you must be familiar with:

- 
The SAP S/4HANA OData API 
- 
Anypoint Connectors 
- 
Mule runtime (Mule) 
- 
Elements and global elements in a Mule flow 
- 
Creating a Mule app using Anypoint Studio or Anypoint Code Builder 

Before creating an app, you must have:

- 
Credentials to access the SAP S/4HANA OData target resource 
- 
Anypoint Platform 
- 
Anypoint Studio or Anypoint Code Builder 
- 
Have a developer account or other valid SAP S/4HANA instance 
- 
Access to the catalog service that allows you to use the service discovery 
- 
A communication user that is assigned to the corresponding communication arrangements for the desired APIs 

## Common Use Case for the Connector

Perform CRUD operations on entity types of SAP S/4HANA’s OData API and process the response.
