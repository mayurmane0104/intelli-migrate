# Setting Up Monitoring for Runtime Fabric Deployments

Monitoring for applications deployed to Runtime Fabric is enabled by default.

## Supported Versions of Mule Runtime Engine

Run your Mule app on a supported Mule runtime version. For supported versions, see [Mule Runtime Release Notes](../release-notes/mule-runtime/mule-esb).

## Runtime Fabric Setup

Follow the instructions for [Setting Up Runtime Fabric](../runtime-fabric/latest/setting-up-runtime-fabric). After you install Runtime Fabric, applications that are running and deployed to Runtime Fabric appear in Monitoring.
