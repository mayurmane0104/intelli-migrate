# MuleSoft Composer Release Notes | MuleSoft Documentation

**Source:** [https://docs.mulesoft.com/composer/ms_composer_ms_release_notes](https://docs.mulesoft.com/composer/ms_composer_ms_release_notes)

---

To prevent excessive errors from abandoned processes and reduce the risk of service incidents, MuleSoft Composer automatically deactivates flows that experience continuous failures and alerts affected users. Deactivation occurs only when a flow meets both of these conditions:

- 
100 or more consecutive errors 
- 
10 or more days of continuous failure 

You can reactivate a deactivated flow at any time.
