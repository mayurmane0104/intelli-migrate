Learn About MuleSoft Vibes

MuleSoft Vibes is a purpose-built assistant for the development lifecycle, available directly in Anypoint Code Builder. Build, deploy, and manage your projects using natural language prompts.

MuleSoft Vibes is the natural-language assistant in Anypoint Code Builder for API specifications, integrations, and related tasks by using the built-in MuleSoft MCP Server and optional custom MCP servers. The end-to-end journey for MuleSoft Vibes consists of various tasks, each with links to relevant content to assist you in completing them.
