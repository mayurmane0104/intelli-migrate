# MuleSoft Developer Hub Release Notes

MuleSoft Developer Hub is a unified experience where humans and AI agents can discover, interact, and automate with MuleSoft APIs, skills, MCP servers, and Terraform. With everything in one place, you can find the right assets faster, reduce integration friction, and build with confidence.

Visit [MuleSoft Developer Hub](https://dev-portal.mulesoft.com) to get started.

## May 28, 2026

### What’s New

- 
The MuleSoft Developer Portal is now named MuleSoft Developer Hub. 
- 
[MCP Servers](https://dev-portal.mulesoft.com/index.html?filter=mcp): MuleSoft platform capabilities packaged as ready-to-use tools for AI agents
- 
[Terraform](https://dev-portal.mulesoft.com/index.html?filter=terraform): MuleSoft Terraform Provider resources and data sources
- 
[More skills](https://dev-portal.mulesoft.com/index.html?filter=skill): Expanded skills library with additional agent-executable workflows across the MuleSoft development lifecycle
- 
Dark mode: New dark theme for the MuleSoft Developer Hub experience 

## May 8, 2026

### What’s New

- 
[MuleSoft Developer Portal](https://dev-portal.mulesoft.com)is now generally available with these features:- 
35 platform APIs organized by category across the MuleSoft development lifecycle 
- 
Skills layer for agent-executable workflows built on top of MuleSoft APIs 
- 
In-browser testing playground for trying APIs and skills 
- 
Searchable, tag-based directory for discovering APIs and skills 
- 
Detailed reference documentation with endpoints, versioning, and full API details 
- 
Feedback mechanism to report issues or contribute via GitHub PRs
