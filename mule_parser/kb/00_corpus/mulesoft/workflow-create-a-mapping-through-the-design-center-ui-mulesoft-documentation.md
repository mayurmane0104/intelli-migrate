# Workflow: Create a Mapping through the Design Center UI

- 
[Define Input and Output Structure of a Transformation](transform-input-output-structure-transformation-design-center-task)Provide expected input and required output structures. 
- 
[Graphically Construct a Mapping](transform-graphically-construct-mapping-design-center-task)Drag elements of the input and drop them onto elements of the output. You can also include fixed values and functions to build out the output. 
- 
[Preview the Output of a Transformation](transform-preview-transformation-output-design-center-task)Verify that the transformation produces the expected output.
