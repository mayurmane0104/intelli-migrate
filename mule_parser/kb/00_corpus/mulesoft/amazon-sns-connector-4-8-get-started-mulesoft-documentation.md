# Amazon SNS Connector 4.8 - Get Started

Anypoint Connector for Amazon SNS (Amazon SNS Connector) provides connectivity to the Amazon Simple Notification Service (Amazon SNS) API, enabling you to build distributed web-enabled applications. Mule apps can use Amazon SNS Connector to easily push real-time notification messages to interested subscribers over multiple delivery protocols.

Release Notes: [Amazon SNS Connector Release Notes](../../release-notes/connector/amazon-sns-connector-release-notes-mule-4)
Exchange: [Amazon SNS Connector in Anypoint Exchange](https://anypoint.mulesoft.com/exchange/com.mulesoft.connectors/mule-amazon-sns-connector)

## About Connectors

Anypoint Connectors are Mule runtime engine extensions that enable you to connect to APIs and resources on external systems, such as Salesforce, Amazon SNS, ServiceNow, and Twitter.

## Before You Begin

Before creating an app, you must:

- 
Have access to the Amazon SNS target resource and Anypoint Platform. 
- 
Understand how to create a Mule app using Anypoint Studio. 
- 
Have AWS Identity and Access Management (IAM) credentials. 

## Next Step

After you have met the prerequisites, you are ready to create an app with [Anypoint Studio](amazon-sns-connector-studio).
