# Managing CloudHub and Hybrid Settings

On the **Settings** page in Anypoint Monitoring, you can:

- 
Find the instructions to install Anypoint Monitoring on an on-premises server to monitor Mule applications running on that server. 
- 
Enable (or disable) monitoring for applications running on Mule. 

## Access the Settings Page

To access the **Settings** page, you must have the Anypoint Monitoring User and the Runtime Manager - Read Applications permissions. See [Granting Permissions and Roles to Users](../access-management/users#granting-permissions-and-roles-to-users).

- 
Log in to Anypoint Platform with a user account that has [permission to access Anypoint Monitoring content](am-permissions).
- 
Navigate to Anypoint Monitoring: Click **Monitoring**from the Anypoint Platform home page or from the**Runtimes**menu in the header.
- 
In the sidebar, click **Settings**.
- 
To monitor applications deployed to a local server, select **Hybrid**, and follow the procedure to install Anypoint Monitoring agent from the latest version of the agent’s installer in`am.zip`.
- 
To enable (or disable) monitoring for apps deployed to CloudHub, select **CloudHub**.

| Anypoint Monitoring is enabled by default for all CloudHub 2.0 applications. |
