# Configuring Text Panels in a Custom Dashboard

[Advanced and Titanium tiers](/monitoring/#billing)

Configure HTML and Markdown text panels in Anypoint Monitoring custom dashboards.

## Before You Begin

Create or navigate to the text panel you plan to configure:

- 
If your text panel exists, open its configuration view: - 
From **Custom Dashboards**, open the custom dashboard that contains your text panel.For guidance, see [View a Custom Dashboard](dashboard-custom-config#view).
- 
Click the text panel’s ![](_images/more-menu-vert-ellipsis.png) ( (**More menu**), and select**Configure**.
 
- 
- 
If the text panel doesn’t exist: - 
Create the text panel. For guidance, see [Add Charts to a Custom Dashboard](dashboard-custom-config#charts_adding).
- 
Navigate to its configuration view. 
 
- 

## Create a Text Panel

Create a text panel in a custom dashboard by following the guidance in [Add Charts to a Custom Dashboard](dashboard-custom-config#charts_adding).

## Configure a Text Panel

Configure a panel with HTML or Markdown text in a custom dashboard.

- 
From **Custom Dashboards**, open the custom dashboard that contains your text panel.For guidance, see [View a Custom Dashboard](dashboard-custom-config#view).
- 
Click the panel’s ![](_images/more-menu-vert-ellipsis.png) ( (**More menu**), and select**Configure**to open the panel’s**General**configuration tab:- 
Provide a title and description. 
- 
Select the **markdown**or**html**mode.
- 
Provide content in the selected mode. For examples and more detailed steps, see: 
 
- 
- 
Click **Apply Changes**.
- 
Exit the configuration view by clicking the **X**next to the configuration tabs.
