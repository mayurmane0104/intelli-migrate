# Using the Command Palette

The Command Palette in Anypoint Code Builder is the control center for all commands you use to perform tasks. Knowing how to open it is important for your productivity.

- 
Open the Command Palette in one of the following ways: - 
Use the keyboard shortcuts: - 
Mac: Cmd+Shift+p 
- 
Windows: Ctrl+Shift+p 
 
- 
- 
In the desktop IDE, select **View**>**Command Palette**.
- 
In the cloud IDE, click the ![](_images/icon-menu.png) (menu) icon, and select (menu) icon, and select**View**>**Command Palette**:![The View and Command Palette options are displayed in a list of menu choices](_images/open-command-palette.png)  
 
- 
- 
Type `MuleSoft:`and browse the available commands:![A text box for entering commands, with a list of recently used and other commands](_images/all-mulesoft-commands.png)  

For a list of MuleSoft commands, see [Command Reference](ref-acb-commands).
