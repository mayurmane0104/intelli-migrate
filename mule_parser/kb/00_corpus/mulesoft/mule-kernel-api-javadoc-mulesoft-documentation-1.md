# Mule Kernel API Javadoc

Access reference information for Mule Kernel Java APIs and review support limitations.

MuleSoft provides Javadocs for the Mule Kernel (formerly called Mule Community Edition). Note that the Mule Kernel doesn’t provide all the functionality of the Mule runtime engine, and development with the Mule Kernel isn’t supported in Anypoint Studio.

The Javadocs contain definitions for classes, fields and their data types, and they also describe methods, including their usage, parameters, and return values.

For a supported and easier way to extend the Mule runtime engine, see [Mule SDK](../../mule-sdk/latest/).
