# Workflow: Create a Mapping through the Anypoint Studio UI

- 
[Define Input and Output Structure of a Transformation](transform-input-output-structure-transformation-studio-task)Provide expected input and required output structures.
- 
[Graphically Construct a Mapping](transform-graphically-construct-mapping-studio-task)Drag elements of the input and drop them onto elements of the output. You can also include fixed values and functions to build out the output.
- 
[Preview the Output of a Transformation](transform-preview-transformation-output-studio-task)Verify that the transformation produces the expected output.
