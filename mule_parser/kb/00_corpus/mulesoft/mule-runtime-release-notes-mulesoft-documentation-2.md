# Mule Runtime Release Notes

Mule follows semantic versioning to denote major, minor, and patch releases.

MuleSoft releases enhance the quality, capabilities, and security of Mule runtime engine (Mule). To take advantage of these improvements, it’s important to adopt a strategy for upgrading your Mule version and to regularly update patches of your Mule deployments with the latest bug fixes and security enhancements.

To upgrade to a new Mule version, see [Mule Upgrades and Patch Updates](#mule-upgrades).
