# Agent Visualizer Release Notes

Agent Visualizer provides a detailed visual graph so you can see, understand, and interact with your enterprise’s evolving network of agents, Model Context Protocol (MCP) servers, and LLMs.

## February 9, 2026

### What’s New

- 
MCP server and tool insights Visualize agent and MCP server relationships to identify active tools ordered by throughput and drill down into specific tools to review instance counts, total calls, and error rates. 
- 
Advanced search capabilities Locate specific nodes instantly using case-insensitive search by display name, asset type, or platform. 
- 
Granular network filtering Isolate specific traffic patterns by filtering your agent network view based on business groups, environments (Production or Sandbox), and activity periods. 

For more information, see [View and Navigate the Agent Network](../../agent-visualizer/view-and-navigate-agent-network).
