# Documenting an API

To increase usability and adoption, create documentation using Einstein generative AI, document APIs using API Notebook, and configure API instances.

- 
[Generating API Documentation with Generative AI](generating-documentation-with-ai)Create API documentation by using Einstein generative AI. 
- 
[Documenting an Asset Using API Notebook](to-use-api-notebook)This feature of the product has reached [End of Life](https://www.salesforce.com/en-us/wp-content/uploads/sites/4/documents/legal/Agreements/versioning-back-support-policy.pdf).Create API Notebooks to document each function in your API and provide a test area so that users can experiment with sending different values to the API and receiving output. After creating your API Notebook, create an API instance to control whether the notebook is private or public.
