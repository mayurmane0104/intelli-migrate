# PagerDuty Connector 1.0

Anypoint Connector for PagerDuty (PagerDuty Connector) enables you to connect to the PagerDuty API. PagerDuty Connector enables Mule applications to manage the entire incident lifecycle, including triggering, acknowledging, and resolving incidents, and configure core PagerDuty assets like Users, Schedules, and Escalation Policies directly from your Mule flows.

For information about compatibility and fixed issues, refer to the PagerDuty Connector Release Notes.

## Before You Begin

To use this connector, you must be familiar with:

- 
The PagerDuty Connector’s API 
- 
Anypoint Connectors 
- 
Mule runtime engine (Mule) 
- 
Elements and global elements in a Mule flow 
- 
How to create a Mule app using Anypoint Code Builder or Anypoint Studio 

Before creating an app, you must have:

- 
Credentials to access the PagerDuty target resource 
- 
Anypoint Platform 
- 
The latest versions of Anypoint Code Builder or Anypoint Studio 

## Next Step

After you complete the prerequisites, you’re ready to create an app and configure the connector using [Anypoint Studio](../../connectors/introduction/intro-config-use-studio) or [Anypoint Code Builder](../../connectors/introduction/intro-config-use-acb).
