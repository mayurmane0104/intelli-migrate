# Publishing Assets

Publish APIs, API Groups, templates, connectors, policies, Mule XML example code, and custom information assets to a private Exchange instance or an Exchange public portal. Exchange provides a repository for code and APIs, and helps your organization access them easily, model them, and reuse them.

A private Exchange instance makes it easy to provide assets to internal developers by giving them viewer, contributor, or administrator access. Additionally, assets created within a business group are automatically provided to the developers of that business group.

An Exchange public portal enables Exchange administrators to provide assets to developers outside of their own organizations.

Both Exchange views also let users review assets so that asset providers can get feedback.

See the [FAQ](exchange2-faq) for additional information.
