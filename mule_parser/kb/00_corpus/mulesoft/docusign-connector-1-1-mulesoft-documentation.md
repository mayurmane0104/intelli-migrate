# DocuSign Connector 1.1

Anypoint Connector for DocuSign (DocuSign Connector) enables you to access the DocuSign platform and exposes operations provided by the DocuSign eSignature API v2.1.

For compatibility information and fixed issues, see the DocuSign Connector Release Notes.

## Before You Begin

To use this connector, you must be familiar with:

- 
The DocuSign API 
- 
Anypoint Connectors 
- 
Mule runtime (Mule) 
- 
Elements and global elements in a Mule flow 
- 
Creating a Mule app using Anypoint Studio or Anypoint Code Builder 

Before creating an app, you must have:

- 
Credentials to access the DocuSign target resource 
- 
Anypoint Platform 
- 
Anypoint Studio or Anypoint Code Builder 

## Authentication Types

DocuSign Connector connections use the following authentication methods:

- 
Authorization Connection Provider (Implicit Grant) 
- 
JWT Connection Provider (JWT Grant) 
- 
OAuth Connection Provider (Authorization Code Grant)
