# MuleSoft Automation Credits 3.0

MuleSoft Automation Credits 3.0 is available in Digital Wallet. Use Automation Credits 3.0 with MuleSoft for Flow: Integration, Anypoint IDP, MuleSoft for Flow: IDP, or a combination of these products, as more fully described in the applicable [Subscription Plan](https://www.salesforce.com/company/legal/mulesoft-subscription-plan/) or Features and Entitlement Document.

If you have MuleSoft Automation Credits 3.0, usage visibility, monthly statements, and overage billing are all centralized within the Salesforce Digital Wallet. If you have an Anypoint Platform organization, view your usage and entitlement details within Anypoint Usage Reports for cross-platform transparency.

| Composer and RPA are moving to the end of sale. As of February 18, 2026, Flow Orchestration is included and does not consume Automation Credits in 3.0. | 

| Usage Type | Description | Conversion rate (Credits per unit) | 
|---|---|---|
| 
 | Integration capabilities within Salesforce Flow; consumes Automation Credits for integration tasks. | 2 credits per successful task | 
| 
 | IDP on Anypoint Platform; consumes credits for IDP document pages. | 30 credits per page | 
| 
 | IDP capabilities within Salesforce Flow; consumes Automation Credits for document processing in Flow. | 30 credits per page | 

Rates and usage types for Automation Credits 3.0 vary by subscription. Refer to the Usage Details table on your Order Form and the applicable Subscription Plan or Features and Entitlement Document.

To learn more about how Omni Credits are consumed, and when other types of credits are consumed with generative AI features, see [Agentforce and Generative AI Usage and Billing](https://help.salesforce.com/s/articleView?id=ai.generative_ai_usage.htm&type=5) in Salesforce Help.
