# Access Asset and Developer Portals

Open a managed API from API Manager into Anypoint Exchange to browse the private asset portal for that version when you have Portals Viewer access or the portal appears on the public developer catalog. You can also start in Exchange under Public portal and select an asset from the organization’s catalog. Administrators review resources, methods, publish dates, and mocking from the same Exchange experience in either path, and they manage sharing and public portal visibility from Anypoint Exchange.

## Open a Private Asset Portal from API Manager

Before you open an asset portal, confirm you meet at least one requirement:

- 
The portal is listed in the organization’s public developer portal. 
- 
The portal is private, but you have Portals Viewer access. 

To open an asset portal:

- 
Navigate to **Anypoint Platform**>**API Manager**.
- 
In **API Administration**, click the name of the API instance that you want to access.
- 
Click **Actions**and select**View API in Exchange**.The portal for the selected asset opens in Exchange. You can share the asset and [make the portal public](../../exchange/about-portals)from Anypoint Exchange.

## Open the Organization’s Public Portal in Exchange

To open an organization’s public portal:

- 
Navigate to **Exchange**>**Public portal**.
- 
From the developer portal page, select the asset that you want to access.
