# Command Reference

Anypoint Code Builder provides a set of commands through the Command Palette.

## MuleSoft Commands

### Platform Commands

- 
Open MuleSoft Vibes from the Command Palette. 
- 
Export troubleshooting information, including logs and workspace details. See [Export Troubleshooting Information](troubleshooting#export-troubleshooting-info).`MuleSoft: Export Troubleshooting Information`command
- 
Import an existing Studio workspace into Anypoint Code Builder. `MuleSoft: Import Studio Workspace`command
- 
Log in to Anypoint Platform from the IDE. See [Log in from the IDE through the Command Palette](start-acb#login-ide).`MuleSoft: Login to Anypoint Platform`command
- 
Open the **Settings**page for Anypoint Code Builder settings, which include settings for the Anypoint Platform host (EU or US). For an example, see[Set the Desktop IDE to the EU or US Cloud](start-acb#change-clouds).`MuleSoft: Open ACB Settings`command
- 
Open the **Welcome**tab for Anypoint Code Builder. See an example in[Discovering the UI](start-discover-ui).`MuleSoft: Show Welcome`command
- 
Open project dependencies in the Explorer view. `MuleSoft: Show Project dependencies`command

### Integration Commands

- 
Deploy an integration or implementation to CloudHub. See [Deploy an App to CloudHub](int-deploy-mule-apps#deploy-an-app-to-cloudhub).`MuleSoft: Deploy Mule Project to CloudHub`command
- 
Start an integration project. You can also start an integration project from the UI. See [Creating Integrations](int-create-integrations).`MuleSoft: Develop an Integration`command
- 
Create a shareable or deployable JAR from your project. See [Export Mule Project](int-export-mule-project#export-mule-project).`MuleSoft: Export Mule Project`command
- 
Download a supported Java Development Kit version for local development. `MuleSoft: Download JDK`command
- 
Download a Mule runtime version for local development. `MuleSoft: Download Mule Runtime`command
- 
Import an API spec from Exchange and scaffold it into an implementation project. See [Scaffold an API and Create an Integration Project](imp-implement-api-specs#scaffold-new-integration).`MuleSoft: Implement an API Specification`command
- 
Import a connector, REST or GraphQL library, or DataWeave library from Anypoint Exchange. See examples in [Import a Connector from Exchange](int-create-integrations#import-connectors-from-exchange),[Import an API Spec into an Existing Implementation Project](imp-implement-api-specs#import-spec-into-project), and[Import a DataWeave Library](int-configure-dw-expressions#import-a-dataweave-library).`MuleSoft: Import Asset from Exchange`command
- 
Import a JAR file for a Mule project and load it into a workspace in the IDE. See [Importing Projects into the IDE](int-import-mule-project).`MuleSoft: Import a Mule Project`command
- 
Open custom metadata management for a Mule project. `MuleSoft: Manage Custom Metadata`command
- 
Publish an integration project to Anypoint Exchange. `MuleSoft: Publish Mule Project to Exchange`command
- 
Save and hot-deploy to a local Mule runtime. `MuleSoft: Save and Hot-deploy to Local Runtime`command
- 
Run a Mule application locally. `MuleSoft: Run Mule Application`command
- 
Run a saved multi-project launch configuration from your workspace. See [Running Multiple Local Integration Projects with MuleSoft Vibes](vibes-run-multiple-integration-projects-locally).`MuleSoft: Run Multi-Project Configuration`command
- 
Open Mule project properties. `MuleSoft: Open Mule Project Properties`command
- 
Toggle the canvas layout between classic and descriptive views. `MuleSoft: Toggle Canvas Layout (Classic/Descriptive)`command

### API and Governance Commands

- 
Add an API spec fragment from Exchange to the project directory to include the fragment in your spec. See [Add a Fragment from Exchange to Your Project](des-create-api-fragments#add-fragment-to-project).`MuleSoft: Add Fragment dependency from Exchange`command
- 
Open the API Console from an API design project. See [Creating and Importing API Specifications](des-create-api-specs).`MuleSoft: Show API Console`command
- 
Start an API design project. You can also start the project from the UI. See [Creating and Importing API Specifications](des-create-api-specs).`MuleSoft: Design an API`command
- 
Scaffold an API spec project located in the IDE into an implementation project. See [Scaffold an API Spec into a New Implementation Project](imp-implement-local-apis).`MuleSoft: Implement this local API`command
- 
Import an API spec from MuleSoft VCS. See [Import an API Specification from MuleSoft VCS](des-create-api-specs#import-spec).`MuleSoft: Import API Specification from MuleSoft VCS`command
- 
Open API project properties. `MuleSoft: Open API Project Properties`command
- 
Publish an API project to Anypoint Exchange. See [Publish an API spec to Exchange](des-publish-api-spec-to-exchange#publish-spec).`MuleSoft: Publish API Project to Exchange`command
- 
Re-scaffold an API after updating a local API spec. See [Re-Scaffold the API Spec](imp-implement-local-apis#rescaffold-api-spec).`MuleSoft: Re-scaffold this local API`command
- 
Open the API Governance panel in an API design project. For information about rulesets, see [Validating API Specifications Against Governance Rulesets](des-govern-api).`MuleSoft: Show API Governance`command
- 
Change a governance ruleset version in an API design project. For information about rulesets, see [Validating API Specifications Against Governance Rulesets](des-govern-api).`MuleSoft: Change Ruleset Version`command
- 
Remove a governance ruleset from an API design project. For information about rulesets, see [Validating API Specifications Against Governance Rulesets](des-govern-api).`MuleSoft: Remove Governance Ruleset`command
- 
Run governance validation across all rulesets and rules in the project. For information about rulesets, see [Validating API Specifications Against Governance Rulesets](des-govern-api).`MuleSoft: Run Governance Validation with all Rulesets and Rules`command
- 
Sync centralized governance rulesets. For information about rulesets, see [Validating API Specifications Against Governance Rulesets](des-govern-api).`MuleSoft: Sync Centralized Rulesets`command
- 
Sync centralized rulesets and run governance validation. For information about rulesets, see [Validating API Specifications Against Governance Rulesets](des-govern-api).`MuleSoft: Sync and Run Validation`command
- 
View API conformance status in Exchange. For information about rulesets, see [Validating API Specifications Against Governance Rulesets](des-govern-api).`MuleSoft: View API Conformance Status on Exchange`command

### Agent Network Commands

- 
Create an Agent Network project. `MuleSoft: Create an Agent Network Project`command
- 
Add Exchange assets to an Agent Network project. `MuleSoft: Add Exchange Assets to Agent Network Project`command
- 
Deploy an Agent Network project. `MuleSoft: Deploy Agent Network`command
- 
Publish Agent Network assets. `MuleSoft: Publish Agent Network Assets`command
- 
Set up Agent Network gateways. `MuleSoft: Set Up Agent Network Gateways`command

## Other Commands

Other helpful commands include the following:

- 
Open a project folder from the Command Palette. For examples, see [Adding Folders to Your Home Directory](start-add-folders).`File: Open Folder`command
- 
Open the Anypoint Code Builder panel from the IDE. The panel provides links to frequent actions. See an example in [Discovering the UI](start-discover-ui).`View: Show Anypoint Code Builder`command
