# Anypoint DataGraph Administration Settings

On the DataGraph Administration settings page, you can select environments, view and edit endpoints, configure policies, and configure client providers:

![The illustration shows the Anypoint DataGraph Administration page](_images/datagraph-settings.png) 

| 1 | Switch Environmentcontrol. Click the control to see a list of environments you have added to your organization. Select an environment to switch. | 
| 2 | Consumer endpointedit options. To edit the current endpoint, click theEdit consumer endpointicon. To revert to the system-generated endpoint, click theReverticon. | 
| 3 | DataGraph Policiesconfiguration options. You can choose to restrict requests to your unified schema from registered client applications only, set SLA-based rate limiting for requests, or allow requests from anyone with access to the unified schema’s endpoint. | 
| 4 | DataGraph external client providerscontrol. To see a list of external client providers previously configured by your organization administrators, click the control. Select a provider from the list. To run queries in Anypoint DataGraph, obtain proper credentials from the external client provider.If your administrators haven’t configured any external client providers, this item is not available. |
