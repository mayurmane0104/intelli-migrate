# Publish API Groups to Exchange

After you create or edit an API Group to add the required API instances, you publish the API Group to Exchange to make it available to consumers.

## Task Prerequisites

Before you begin, ensure that you have permissions to all the assets in the API Group instance in Exchange.

### To publish API Groups to Exchange:

- 
Navigate to **Anypoint Platform**>**API Manager**.
- 
Click **API Groups**.
- 
From the API Groups details page, click the **API Group version**that you want to publish and click the**API Group instance**.The API Group instance page is displayed: ![Publishing API Groups to Exchange](_images/publish-api-product-to-exchange.png)  
- 
If the instance is not already published to Exchange, the **Publish to Exchange**button appears on the page.
- 
Click **Publish to Exchange**.
- 
On the **Publish**window, specify the name for the API Group asset and the version.
- 
Click **Publish**.
