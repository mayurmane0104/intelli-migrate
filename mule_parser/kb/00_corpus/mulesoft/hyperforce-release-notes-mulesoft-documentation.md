## March 30, 2026

### What’s New

- 
Anypoint Insights dashboards introduce new charts and visualizations of metrics in EU, US, Japan (JP), and Canada (CA) cloud instances of Anypoint Platform on the Hyperforce infrastructure. These app and API metrics bring Anypoint Insights dashboards into near parity with metrics displayed through the built-in dashboards in Anypoint Monitoring. For details, see [Anypoint Monitoring Release Notes](../monitoring/anypoint-monitoring-release-notes#march-30-2026).

## January 30, 2026

### What’s New

- 
In Canada Cloud and Japan Cloud instances of Anypoint Platform, Telemetry Exporter is now available to organizations with the Advanced subscription tier. Centralize observability with Telemetry Exporter by exporting audit log and trace data to your third-party monitoring ecosystem. Telemetry Exporter: [Exporting Telemetry Data to Third-Party Monitoring Systems](../../monitoring/telemetry-exporter).For information about subscription tiers, see [Anypoint Platform Packages and Plans](../../monitoring/#billing).
