# Add API Instances

- 
[Adding a Mule Gateway API Instance](create-instance-task-mule)
 Use Mule Gateway if you have APIs on Mule Runtime that need an API gateway to manage, observe, and secure your APIs.
- 
[Adding an Omni Gateway API Instance](create-instance-task-flex)
 Use Omni Gateway for any APIs that need a flexible and performant API gateway that works with distributed and microservices environments and fits into your CI/CD environments.
- 
[Adding an Omni Gateway Agent or Tool Instance](create-instance-task-agent-tool)
 Use Omni Gateway for any agent, broker, LLM, or MCP server that needs a flexible and performant gateway that works with distributed and microservices environments and fits into your CI/CD environments.
- 
[Adding an MCP Bridge Instance](create-instance-task-mcp-bridge)
 Use Omni Gateway MCP Bridge to create MCP servers to expose your current API instances as MCP tools so agents can discover and call them.
- 
[Adding an MCP Server from Public Exchange](create-instance-public-exchange)
 Use Public Exchange to add an MCP Server from a public exchange asset.
