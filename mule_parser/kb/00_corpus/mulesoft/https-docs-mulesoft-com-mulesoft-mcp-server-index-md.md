# MuleSoft MCP Servers Overview > For the full documentation index, see: https://docs.mulesoft.com/llms.txt MuleSoft MCP Servers implement the Model Context Protocol (MCP) so AI assistants in your IDE can work with MuleSoft products and services. MuleSoft DX MCP Server supports API design, application deployment, and asset management. MuleSoft Platform MCP Server supports service discovery, policy enforcement, and traffic monitoring across your organization. ## MuleSoft DX MCP Server MuleSoft DX MCP Server provides structured, permission-scoped access to Anypoint Platform from AI assistants in your IDE to help you design, build, publish, deploy, and secure MuleSoft assets by turning natural-language goals into production-ready actions. Typical lifecycle areas you address with MuleSoft DX MCP Server include: - API specification development - Application creation and configuration - Agent network creation - Asset publication in Exchange - Instance deployment and management to CloudHub 2.0 and Runtime Fabric - Application security [Getting Started with MuleSoft DX MCP Server](getting-started) ## MuleSoft Platform MCP Server MuleSoft Platform MCP Server provides governed access to your entire IT landscape, including APIs, agents, MCP servers, and LLMs, to accelerate production-ready AI at scale. It helps you scan, discover, govern, and monitor services across the infrastructure you already run. Typical platform areas you address with MuleSoft Platform MCP Server include: - Service scanning across agentic platforms - Discovery of APIs, agents, MCP servers, and LLMs in one place - Policy enforcement for PII detection, semantic routing, and token controls - Monitoring of traffic, cost, and performance across services [Getting Started with MuleSoft Platform MCP Server](getting-started-platform)
