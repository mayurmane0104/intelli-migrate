# Administrator Tasks

Exchange administrators have permissions to perform these tasks:

- 
[Discover and catalog external agents](discovering-and-importing-external-agents)Use agent scanners to automatically discover and catalog agents from outside Anypoint Platform. 
- 
Import Agentforce agents into Exchange to include them in business groups. 
- 
Share an asset to publish an API asset to a public portal, or to grant access to an asset to specific users in your organization, to everyone in your organization, or to everyone in a chosen external organization. 
- 
[Publish an API to a public portal](to-share-api-asset-to-portal)Publish APIs to a public portal for external users. 
- 
Save and maintain searches for assets within a business group. 
- 
[Use API Manager to add the Request Access button](to-enable-the-request-access-button)Specify which API assets can be shared with users. 
- 
Grant the Exchange Administrator, Contributor, Viewer, or Creator permissions to members of your organization, and optionally provide access for individual assets. 
- 
Find information about Exchange cookies, cookie configuration, and cookies for vanity domains. 
- 
[Migrate Exchange 1 assets to Exchange 2](migrate)Move assets from Exchange 1.
