# Access Management Overview > For the full documentation index, see: https://docs.mulesoft.com/llms.txt Access Management is the central hub for managing user access, authentication, and permissions across your Anypoint Platform organization. Use Access Management to [create your Anypoint Platform account](managing-your-account#how-to-create-your-account) and configure your user profile. Organization owners and administrators can use Access Management to: - [Invite and manage users](users) in your organization. - Create [business groups](business-groups) to contain your Anypoint Platform resources such as apps and APIs. - Create [environments](environments) to manage app and API deployment. - [Assign permissions to individual users](managing-permissions) or set up hierarchical user management by using the [Teams](teams) feature to manage access to assets and areas of your organization. - Manage user identity and configure single sign-on (SSO) by using [external identity providers (IdPs)](external-identity). - Protect your organization from unauthorized access by using [multi-factor authentication](multi-factor-authentication). - Authorize client applications by configuring [external client providers](managing-api-clients). - View user and connected app activity by using [audit logs](audit-logging). - Develop and configure [connected apps](connected-apps-overview) to delegate access to Anypoint Platform. - Grant [external organizations](external-organization-access) access to your resources to enable cross-organization collaboration. Access Management also provides a REST API for you to programmatically access the resources related to user and client management, organizations and business groups, and roles and permissions. To use the Access Management API, see the [Access Management API Portal](https://dev-portal.mulesoft.com/apis/access-management.html). Depending on your [Anypoint Platform deployment type](../hosting-home/), some Access Management features may be unavailable to your organization.
