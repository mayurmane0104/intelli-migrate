# MuleSoft Government Cloud Release Notes

These release notes describe updates to MuleSoft Government Cloud as from January 10, 2024.

## April 8, 2025

### What’s New

- 
MuleSoft Government Cloud now supports Mule runtime engine version 4.9.3. 

## May 8, 2024

### What’s New

- 
MuleSoft Government Cloud now supports Java 17. For more information, visit [Java Support](../../general/java-support).

## March 12, 2024

### What’s New

- 
MuleSoft Government Cloud now supports Mule runtime engine version 4.6. The March CloudHub 1.0 release introduces patches for Runtime versions 4.3.0 and 4.4.0 and Runtime 4.6. This update is a breaking change as it enforces compliance with FIPS 140-2 on runtime versions 4.6, 4.4, and 4.3 for CloudHub applications within the MuleSoft Government Cloud. For more details about the impact of this update, check this article: - 
[GovCloud - March 2024 - Updates on FIPS Enforcement.](https://help.salesforce.com/s/articleView?id=001186489&type=1)
 
- 

## January 10, 2024

### What’s New

- 
Trusted domains allowlisting is now available in MuleSoft Government Cloud. For more information, visit [Allowing Trusted Domains for API Platform Proxies](../../gov-cloud/gov-cloud-security#allowing-trusted-domains-for-api-platform-proxies).
