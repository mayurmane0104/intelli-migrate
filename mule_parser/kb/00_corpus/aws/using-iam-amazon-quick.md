# Using IAM - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/iam.html](https://docs.aws.amazon.com/quick/latest/userguide/iam.html)

---

AWS Identity and Access Management (IAM) is an AWS service that helps an administrator securely control access
      to AWS resources. IAM administrators control who can be *authenticated* (signed in) and *authorized*
      (have permissions) to use Amazon Quick resources. IAM is an AWS service that you can
      use with no additional charge.
