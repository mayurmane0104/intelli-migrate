# AWS Toolkit for Visual Studio Code Documentation

The AWS Toolkit for Visual Studio Code is a plugin for the Visual Studio Code (VS Code) editor. The Toolkit makes it easier for developers to develop, debug, and deploy applications that use Amazon Web Services.

## AWS Toolkit for Visual Studio Code

- Contains code examples and other types of examples to help accelerate your development of applications that work with AWS services. The examples show how to perform specific tasks for AWS services using various programming languages and supported technologies.
