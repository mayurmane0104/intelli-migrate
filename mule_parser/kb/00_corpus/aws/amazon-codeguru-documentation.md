# Amazon CodeGuru Documentation

CodeGuru provides intelligent recommendations for improving application performance,
    efficiency, security, and code quality.

## Amazon CodeGuru Profiler

- Describes the AWS CLI commands that you can use to work with profiling groups.

## Amazon CodeGuru Reviewer

- Describes the AWS CLI commands that you can use to work with CodeGuru Reviewer repository associations and code reviews.
- Lists all detectors that Amazon CodeGuru Security uses to analyze code. Provides detailed information about the detectors, their impact on applications, and ways to mitigate risk.
