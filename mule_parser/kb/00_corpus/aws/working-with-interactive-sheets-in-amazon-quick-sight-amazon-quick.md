# Working with interactive sheets in Amazon Quick Sight - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/working-with-interactive-sheets.html](https://docs.aws.amazon.com/quick/latest/userguide/working-with-interactive-sheets.html)

---

An *Interactive Sheet* is a collection of data expressed in visuals
        that users can interact with when the sheet is published to a dashboard. Amazon Quick
        authors can add different layouts, controls, and filters to their interactive sheets that
        dashboard viewers can use to gain detailed information from the published data. By default,
        every sheet in an analysis is an interactive sheet. If your account doesn't have the
            **Pixel perfect reporting Add-on**, you can only create and publish
        interactive sheets.

For more information on creating an interactive sheet, see [Starting an analysis in Quick Sight](./creating-an-analysis.html).
