# Sorting dashboard data in Amazon Quick Sight - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/sorting-dashboard-data.html](https://docs.aws.amazon.com/quick/latest/userguide/sorting-dashboard-data.html)

---

You can sort data in three ways:

- 
                    You can hover over the label for the field you want to sort by, and choose the sort icon. 
- 
                    You can choose the filter icon at the upper right of one of the dashboard elements. 
- 
                    You can click or tap on the field and choose **Sort**from the context menu.

Sorting for pivot tables is different; you specify the sort order by using the column sort icon on the pivot table.
