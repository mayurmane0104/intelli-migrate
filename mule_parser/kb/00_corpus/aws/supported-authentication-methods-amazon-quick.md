# Supported authentication methods - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/qbiz-indexes-supported-authentication.html](https://docs.aws.amazon.com/quick/latest/userguide/qbiz-indexes-supported-authentication.html)

---

The authentication methods supported depend on your implementation type:

## IDC Implementation

            - 
                    Amazon Quick: AWS Identity Center authentication only 
- 
                    Amazon Q Business: `AWS_IAM_IDC`

## Non-IDC Implementation

            - 
                    Amazon Quick: - 
                            Native identities (username/password) 
- 
                            AWS Managed Microsoft AD 
- 
                            IAM federation 
 
- 
                            
- 
                    Amazon Q Business: `AWS_QUICKSIGHT_IDP`
