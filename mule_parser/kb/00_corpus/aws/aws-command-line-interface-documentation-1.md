# AWS Command Line Interface Documentation

The AWS Command Line Interface (AWS CLI) is a unified tool that provides a consistent
        interface for interacting with all parts of Amazon Web Services. AWS CLI commands for different services are
        covered in the accompanying user guide, including descriptions, syntax, and usage
        examples.
