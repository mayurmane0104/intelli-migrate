# Revoking access to an analysis - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/revoke-access-to-an-analysis.html](https://docs.aws.amazon.com/quick/latest/userguide/revoke-access-to-an-analysis.html)

---

Use the following procedure to revoke access to an analysis.

###### To revoke access to an analysis

- 
	Open the [Quick console](https://quicksight.aws.amazon.com/).
- 
                    Open the analysis that you want to change. 
- 
                    On the analysis page, choose **File**on the application bar, and then choose**Share**.
- 
                    Choose **Manage analysis permissions**.
- 
                    Locate the user or group whose access you want to revoke, and then choose the trash-can icon next to the user or group. 
- 
                    Choose **Confirm**.
