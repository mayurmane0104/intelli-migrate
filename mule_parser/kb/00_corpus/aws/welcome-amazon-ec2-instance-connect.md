# Welcome - Amazon EC2 Instance Connect

**Source:** [https://docs.aws.amazon.com/ec2-instance-connect/latest/APIReference/index.html](https://docs.aws.amazon.com/ec2-instance-connect/latest/APIReference/index.html)

---

This is the * Amazon EC2 Instance Connect API Reference*. It
            provides descriptions, syntax, and usage examples for each of the actions for Amazon EC2
            Instance Connect. Amazon EC2 Instance Connect enables system administrators to publish
            one-time use SSH public keys to EC2, providing users a simple and secure way to connect
            to their instances.

To view the Amazon EC2 Instance Connect content in the * Amazon EC2 User
                Guide*, see [Connect to
                your Linux instance using EC2 Instance Connect](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/Connect-using-EC2-Instance-Connect.html).

For Amazon EC2 APIs, see the [Amazon EC2 API
                Reference](https://docs.aws.amazon.com/AWSEC2/latest/APIReference/Welcome.html).
