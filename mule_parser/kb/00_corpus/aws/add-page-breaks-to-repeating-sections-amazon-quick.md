# Add page breaks to repeating sections - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/qs-reports-repeat-sections-page-break.html](https://docs.aws.amazon.com/quick/latest/userguide/qs-reports-repeat-sections-page-break.html)

---

Similar to section page breaks, you can add page breaks to repeating sections.

###### To add a page break to a repeating section

- 
                            Navigate to the section that contains the repeating behavior that you want to change and choose the **Edit repeating section**(triple panel) icon.
- 
                            In the **Repeating**tab of the**Edit section**pane that appears, check the box titled**Page break after each instance**.

An instance is defined as a distinct value of a dimension or a unique
                        combination of values of multipledimensions. If you clear the **Page
                            break after each instance** checkbox, the page break is
                        removed.
