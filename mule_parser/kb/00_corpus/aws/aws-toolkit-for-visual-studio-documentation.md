# AWS Toolkit for Visual Studio Documentation

The AWS Toolkit for Visual Studio is a plug-in for the Visual Studio integrated development
    environment (IDE). The Toolkit for Visual Studio makes it easier for developers to develop, debug, and
    deploy .NET applications that use Amazon Web Services.

- Contains code examples and other types of examples to help accelerate your development of applications that work with AWS services. The examples show how to perform specific tasks for AWS services using various programming languages and supported technologies. Note that the PDF has a large file size.
