# Orienting pivot table values - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/pivot-table-value-orientation.html](https://docs.aws.amazon.com/quick/latest/userguide/pivot-table-value-orientation.html)

---

You can choose to display a pivot table in a columnar or row-based format. Columnar is the default. When you change to a row-based format, a column with the value name is added to the right of the row header column.

###### To change a pivot table format

- 
					On the analysis page, choose the pivot table visual that you want to edit. 
- 
					Expand the **Field wells**pane by choosing the field wells at the top of the visual.
- 
					On the **Values**field well, choose one of the following options:- 
							Choose **Column**for a columnar format.
- 
							Choose **Row**for a row format.###### NoteIf you use only one metric, you can eliminate the repeated header by formatting the visual and styling it with the **Hide single metric**option.
