# Return a field's format to default settings - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/set-field-format-to-default.html](https://docs.aws.amazon.com/quick/latest/userguide/set-field-format-to-default.html)

---

Use the following procedure to return a field's format to the default settings.

###### To return a field's format to the default settings

- 
							In the **Field list**pane, choose the selector icon to the right of the field that you want to reset.
- 
							Choose **Format**, and then choose**More Formatting options**.The **Format data**pane opens.
- 
							Choose **Reset to defaults**.
