# AWS SDK for SAP ABAP

AWS SDK for SAP ABAP provides an interface to Amazon Web
    Services in ABAP. Using the SDK, you can build SAP applications on top of Amazon S3,
      Amazon EC2, DynamoDB, and more.

- Describes the API operations of AWS SDK for SAP ABAP in detail. The guide also provides sample requests, responses, and errors for the supported web services protocols.
- Contains code and other types of examples to accelerate your development of applications that work with AWS services. The examples show how to perform tasks for AWS services using supported programming languages and technologies.
