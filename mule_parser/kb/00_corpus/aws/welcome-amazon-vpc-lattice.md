# Welcome - Amazon VPC Lattice

**Source:** [https://docs.aws.amazon.com/vpc-lattice/latest/APIReference/index.html](https://docs.aws.amazon.com/vpc-lattice/latest/APIReference/index.html)

---

Amazon VPC Lattice is a fully managed application networking service that you use to connect, secure,
   and monitor all of your services across multiple accounts and virtual private clouds (VPCs).
   Amazon VPC Lattice interconnects your microservices and legacy services within a logical boundary, so that
   you can discover and manage them more efficiently. For more information, see the [Amazon VPC Lattice User Guide](https://docs.aws.amazon.com/vpc-lattice/latest/ug/)
