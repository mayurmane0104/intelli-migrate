# Amazon CodeCatalyst Documentation

Amazon CodeCatalyst is a cloud-based collaboration space for 
    software development teams. CodeCatalyst provides one place where you can plan work, 
    collaborate on code, and build, test, and deploy applications with continuous 
    integration/continuous delivery (CI/CD) tools.

- Learn how to use Amazon CodeCatalyst to track work, develop code, and build, test, and deploy your applications.
- ### Blueprints ResourcesLearn how to use blueprints to create new projects or apply them to existing projects. Also learn how to develop custom blueprints for your spaces. The open-source GitHub repository provides access to the blueprints SDK and sample blueprints.
- Learn how administrators can set up the support plan and roles required to create and manage support cases for their CodeCatalyst space. Once configured, space and project members can create support cases through Support for Amazon CodeCatalyst.
- ### Additional ResourcesLearn more about how to use Amazon CodeCatalyst, common questions, and how to get help from the community when using CodeCatalyst.
