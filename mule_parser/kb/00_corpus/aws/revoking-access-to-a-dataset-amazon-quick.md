# Revoking access to a dataset - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/revoke-access-to-a-data-set.html](https://docs.aws.amazon.com/quick/latest/userguide/revoke-access-to-a-data-set.html)

---

If you have owner permissions on a dataset, you can use the following procedure to revoke user access to a dataset.

###### To revoke user access to a dataset if you have owner permissions for it

- 
					From the Quick start page, choose **Data**at left.
- 
					On the **Data**page, choose the dataset that you want to share.
- 
					On the dataset details page that opens, choose the **Permissions**tab.A list of all users and groups with access to the dataset is displayed. 
- 
					In the **Actions**column for the user or group, choose**Revoke access**.
