# Non-admin sign-up process - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/non-admin-sign-up.html](https://docs.aws.amazon.com/quick/latest/userguide/non-admin-sign-up.html)

---

If you are not an administrator, you can sign up for Quick using a link provided by your admin. This process allows you to create your account and configure your Quick environment.

###### To sign up as a non-admin user

- 
                    **Getting your sign-up link**Sign up for Amazon Quick with the link provided by your admin. 
- 
                    **Account creation and Quick access**After you've created your account, from within Quick, search for Amazon Quick. 
- 
                    **Account configuration**Enter your Account name, Email, Region, and Authentication method. - 
                            For authentication, Amazon Quick supports Pro license integration with start URL format: https://amzn.awsapps.com/start 
- 
                            Default Region is us-east-1 
 
- 
                            
- 
                    **Plan selection**Select the plan and storage options you are using for your instance of Amazon Quick.
