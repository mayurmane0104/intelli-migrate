# Remove a dataset from an analysis - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/delete-a-data-set-from-an-analysis.html](https://docs.aws.amazon.com/quick/latest/userguide/delete-a-data-set-from-an-analysis.html)

---

Use the following procedure to delete a dataset from an analysis.

###### To delete a dataset from an analysis

- 
					On the analysis page, navigate to the **Data**pane and expand the**Dataset**dropdown.
- 
					Choose **Manage datasets**.
- 
					Choose the ellipsis (three dots) next to the dataset that you want to replace, and then choose **Remove**. You can't delete a dataset if it's the only one in the analysis.
- 
					Choose **Close**to close the dialog box.
