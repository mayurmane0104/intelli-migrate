# Tracking dashboards and analyses that use a dataset - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/track-analytics-that-use-dataset.html](https://docs.aws.amazon.com/quick/latest/userguide/track-analytics-that-use-dataset.html)

---

When you create a dataset in Quick Sight, you can track which dashboards and analyses use that dataset. This approach is useful when you want to see which resources will be affected when you make changes to a dataset, or want to delete a dataset.

Use the following procedure to see which dashboards and analyses use a dataset.

###### To track resources that use a dataset

- 
				From the Quick start page, choose **Data**in the pane at left.
- 
				On the **Data**page, choose the dataset that you want to track resources for.
- 
				In the page that opens for that dataset, choose **Edit dataset**.
- 
				In the data preparation page that opens, choose **Manage**at upper right, and then choose**Usage**.
- 
				The dashboards and analyses that use the dataset are listed in the pane that opens.
