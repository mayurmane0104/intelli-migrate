# Creating knowledge bases from Amazon Q Business indexes - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/qbiz-indexes-creating-datasets.html](https://docs.aws.amazon.com/quick/latest/userguide/qbiz-indexes-creating-datasets.html)

---

After setting up permissions, Admin or Admin Pro users can create knowledge bases from Amazon Q Business indexes:

- 
                Sign in to the Amazon Quick console as an Admin or Admin pro user. 
- 
                Navigate to **Knowledge bases**.
- 
                Choose **Create knowledge base**.
- 
                Select **Amazon Q Business**as the data source.
- 
                Choose the Amazon Q Business index you want to use from the list of available indexes. 
- 
                Provide a name and description for the knowledge base. 
- 
                Choose **Create**to create the knowledge base.

###### Note

If multiple Admin users create knowledge bases from the same Amazon Q Business index, these knowledge bases will functionally be identical.
