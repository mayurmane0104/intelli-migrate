# AWS SDK for .NET documentation

The SDK for .NET makes it easier for Windows developers to build .NET applications that tap
    into cost-effective, scalable, and reliable AWS infrastructure services such as Amazon S3, Amazon EC2, and Amazon DynamoDB.

## Latest version (V4)
