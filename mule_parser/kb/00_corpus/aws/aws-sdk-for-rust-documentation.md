# AWS SDK for Rust Documentation

The AWS SDK for Rust provides easy-to-use APIs and utilities developers can use to quickly integrate Rust applications with AWS services such as Amazon S3 and Amazon EC2.

- The AWS SDK for Rust contains one crate for each AWS service, as well as aws-config, which implements configuration loading such as credential providers.
- Contains code and other types of examples to accelerate your development of applications that work with AWS services. The examples show how to perform tasks for AWS services using supported programming languages and technologies.
