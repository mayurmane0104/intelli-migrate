# AWS SDK for Go Documentation

The AWS SDK for Go provides APIs and utilities that developers can use to quickly
    integrate Go applications with AWS services like Amazon S3 and Amazon EC2.

## Latest version (Version 2)

- Describes all of the API operations for the SDK and provides sample requests for the supported web services protocols.

## Previous version (Version 1)

- Describes all of the API operations for the AWS SDK for Go (v1) and provides sample requests for the supported web services protocols.

## Additional resources

- GitHub repository containing code examples to help accelerate your development of applications that work with AWS services. The examples show how to perform specific tasks for AWS services using various programming languages and supported technologies.
