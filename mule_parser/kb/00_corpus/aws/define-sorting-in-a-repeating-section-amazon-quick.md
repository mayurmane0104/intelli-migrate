# Define sorting in a repeating section - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/qs-reports-repeat-sections-sort.html](https://docs.aws.amazon.com/quick/latest/userguide/qs-reports-repeat-sections-sort.html)

---

###### To define sorting in a repeating section

- 
                            Navigate to the section that you want to add a repeating behavior to and choose the **Edit repeating section**(triple panel).
- 
                            In the **Edit section**that opens, choose the ellipsis (three dots) next to the dimension that you want to change.
- 
                            Navigate to the **Repeating**tab and choose the ellipsis (three dots) next to the dimension that you want to sort, and then choose**Edit**.
- 
                            For **Sort by**, use the dropdown to choose the dimension that you want to sort by.
- 
                            For **Aggregation**dropdown, choose the aggregation that you want to specify.
- 
                            For **Sort order**, choose**Ascending**or**Descending**.
