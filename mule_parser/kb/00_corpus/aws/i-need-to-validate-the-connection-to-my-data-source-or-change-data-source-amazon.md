# I need to validate the connection to my data source, or change data source settings - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/troubleshoot-connect-validate.html](https://docs.aws.amazon.com/quick/latest/userguide/troubleshoot-connect-validate.html)

---

In some cases, you might need to update your data source, or you got a connection error and need to check your settings. If so, take the following steps.

###### To validate your connection to the data source

- 
					From the Quick Sight homepage, choose **Data**at left.
- 
					Choose **New**then**Dataset**.
- 
					You will see a list of existing data sources. 
- 
					Choose the data source that you want to test or change. 
- 
					If the option is offered, choose **Edit/Preview data**.
- 
					Choose **Validate connection**.
- 
					Make any changes that you want to make, then choose **Update data source**.
