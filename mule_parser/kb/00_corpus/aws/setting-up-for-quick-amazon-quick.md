# Setting up for Quick - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/admin-setting-up.html](https://docs.aws.amazon.com/quick/latest/userguide/admin-setting-up.html)

---

This section helps you understand how to configure identity and access management, and control sign-up for users when you set up an Amazon Quick instance.

###### Note

For information about how to set up your Amazon Quick instance, including creating
                an AWS account, signing up for an Amazon Quick subscription, and signing in to
                Amazon Quick, see [Setting up and signing into Amazon Quick](https://docs.aws.amazon.com/quicksuite/latest/userguide/setting-up.html).
