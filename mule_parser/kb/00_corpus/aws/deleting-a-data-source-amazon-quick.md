# Deleting a data source - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/delete-a-data-source.html](https://docs.aws.amazon.com/quick/latest/userguide/delete-a-data-source.html)

---

You can delete a data source if you no longer need it. Deleting a query-based
				database data source makes any associated datasets unusable. Deleting an Amazon S3,
				Salesforce, or SPICE-based database data source doesn't affect your
				ability to use any associated datasets. This is because the data is stored in [SPICE](./spice.html). However, you can no longer refresh
				those datasets.

###### To delete a data source

- 
					Choose the data source that you want to delete. 
- 
					Choose **Delete**.
