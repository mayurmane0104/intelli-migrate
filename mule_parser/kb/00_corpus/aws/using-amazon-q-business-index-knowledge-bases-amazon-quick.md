# Using Amazon Q Business index knowledge bases - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/qbiz-indexes-using.html](https://docs.aws.amazon.com/quick/latest/userguide/qbiz-indexes-using.html)

---

Once created, Amazon Q Business index knowledge bases can be used in Amazon Quick just like any other knowledge base:

## Using in spaces

            Admins can add Amazon Q Business index knowledge bases to spaces:

- 
                    Navigate to the space where you want to add the knowledge base. 
- 
                    Choose **Add resources**.
- 
                    Select **Knowledge bases**.
- 
                    Choose the Amazon Q Business index knowledge base from the list. 
- 
                    Choose **Add**to confirm.

## Using in output cards

            Admins can use Amazon Q Business index knowledge bases via Spaces in output cards.

## Using with agents

            Admins can add Amazon Q Business index knowledge bases to custom agents:

- 
                    Navigate to **Agents**.
- 
                    Select an existing agent or create a new one. 
- 
                    In the agent configuration, choose **Add knowledge bases**.
- 
                    Select the Amazon Q Business index knowledge base from the list. 
- 
                    Choose **Add**to confirm.

## Using with automations

            Admins can add Amazon Q Business index knowledge bases to automations:

- 
                    Navigate to **Automations**.
- 
                    Select an existing automation or create a new one. 
- 
                    In the automation configuration, add a step that uses knowledge bases. 
- 
                    Select the Amazon Q Business index knowledge base from the list. 
- 
                    Configure the step and save the automation. 

## Querying knowledge bases

            Readers can query Amazon Q Business index knowledge bases through the Amazon Quick web application. However, a user will only be able to get a response from the Amazon Q Business index if they also have access to the Amazon Q Business application. To query the knowledge base:

- 
                    Navigate to the Amazon Quick web application. 
- 
                    Select a space that contains the Amazon Q Business index knowledge base or use the default agent. 
- 
                    Enter your query in the chat interface. 
- 
                    View the response, which includes citations and clickable links to the source documents from the Amazon Q Business index.
