# Publishing a previous version of an Amazon Quick Sight dashboard - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/publishing-a-previous-dashboard-version.html](https://docs.aws.amazon.com/quick/latest/userguide/publishing-a-previous-dashboard-version.html)

---

Each time you make updates to an analysis and publish it, a new version of the
				Amazon Quick Sight dashboard is created. To revert back to a previous version of a dashboard,
				you can search for it under the dashboard’s **Version History** and
				publish the former version you are interested in. Each dashboard can store up to
				1000 versions that are never deleted. Use the following procedure to publish a
				previous version of a dashboard.

###### To publish a previous version of a dashboard

- 
					On the **Dashboards**tab of the Amazon Quick homepage, choose the dashboard that you want to manage.
- 
					Choose **Version History**on the toolbar on the right. The version of the dashboard that is currently published, as well as previous available versions, will appear in a list. Any comments that were added in the notes section will appear with the respective version.
- 
					Select the version of the dashboard you are interested in. You can see when this version was published and which user published it. 
- 
					To revert to this version, select **Publish**. Click**Confirm**to publish the version.
