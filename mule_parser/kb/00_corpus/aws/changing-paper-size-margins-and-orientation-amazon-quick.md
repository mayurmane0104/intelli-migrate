# Changing paper size, margins, and orientation - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/qs-reports-paper-size.html](https://docs.aws.amazon.com/quick/latest/userguide/qs-reports-paper-size.html)

---

After you create a pixel perfect report in Amazon Quick Sight, you can change the report format,
                orientation, and margins from the **Analysis settings** menu
                whenever you want.

## To change the paper size of a pixel perfect report

                - 
                        From the Quick homepage, choose **Analyses**, and then choose the analysis that contains the pixel perfect report that you want to change.
- 
                        Choose **Sheets**in the file menu and select**Layout Settings**.
- 
                        Open the **Paper size**dropdown menu and choose the paper size that you want. Choose from the following options:- 
                                US letter (8.5 x 11 in.) 
- 
                                US legal (8.5 x 14 in.) 
- 
                                A0 (841 x 1189 mm) 
- 
                                A1 (594 x 841 mm) 
- 
                                A2 (420 x 594 mm) 
- 
                                A3 (297 x 420 mm) 
- 
                                A4 (210 x 297 mm) 
- 
                                A5 (148 x 210 mm) 
- 
                                Japan B4 (257 x 364 mm) 
- 
                                Japan B5 (182 x 257 mm) 
 
- 
                                
- 
                        Choose **Apply**.

## To change the orientation of a report

                - 
                        From the Quick homepage, choose **Analyses**, and then choose the analysis that contains the pixel perfect report that you want to change.
- 
                        Choose the **Settings**icon on the left.
- 
                        Choose the orientation for your report, and then choose **Apply**.

## To change the margins of a report

                - 
                        From the Quick start page, choose **Analyses**, and then choose the analysis that contains the pixel perfect report that you want to change.
- 
                        Choose **Edit < Analysis Settings**.
- 
                        Enter the margin values that you want your report to have, and then choose **Apply**.

Margin values are applied to every page of a pixel perfect report. You can't set
                    custom settings for specific pages in a report, but you can set custom margins
                    for sections using section padding. For more information on section padding, see
                        [Section padding](./qs-reports-section-padding.html). Margin values are expressed in
                    inches. The default margins for all reports are 0.5 inches.
