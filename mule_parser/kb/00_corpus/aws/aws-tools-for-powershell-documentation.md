# AWS Tools for PowerShell Documentation

AWS Tools for PowerShell and AWS Tools for PowerShell Core are PowerShell modules, built on
    functionality exposed by the SDK for .NET, that enable you to script operations on AWS resources from the PowerShell command line. Although you use the SDK's service clients and methods to
    implement the cmdlets, the cmdlets give you a PowerShell experience to specify parameters and handle
    results. For example, the cmdlets in both modules support PowerShell pipelining to pipe PowerShell objects
    to and from the cmdlets.
