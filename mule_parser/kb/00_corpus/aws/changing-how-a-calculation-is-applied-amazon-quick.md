# Changing how a calculation is applied - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/change-how-a-calculation-is-applied.html](https://docs.aws.amazon.com/quick/latest/userguide/change-how-a-calculation-is-applied.html)

---

Use the following procedure to change the way a table calculation is applied to a pivot table.

###### To change the way a table calculation is applied to a pivot table

- 
							Expand the **Field wells**pane by choosing field wells at the top of the visual.
- 
							Choose the field in the **Values**well that has the table calculation that you want to change, choose**Calculate as**, and then choose the way that you want the calculation applied.
