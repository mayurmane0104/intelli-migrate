# What Is the AWS SDK for PHP Version 3? - AWS SDK for PHP

**Source:** [https://docs.aws.amazon.com/sdk-for-php/v3/developer-guide/welcome.html](https://docs.aws.amazon.com/sdk-for-php/v3/developer-guide/welcome.html)

---

The AWS SDK for PHP Version 3 enables PHP developers to use [Amazon Web Services](https://aws.amazon.com/) in their PHP code, and build robust applications and software using
      services like Amazon S3, Amazon DynamoDB, and Amazon Glacier. You can get started in minutes by installing the SDK
      through Composer — by requiring the 

`aws/aws-sdk-php` package — or by downloading
      the standalone [or](https://docs.aws.amazon.com/aws-sdk-php/v3/download/aws.zip)

`aws.zip`[file.](https://docs.aws.amazon.com/aws-sdk-php/v3/download/aws.phar)

`aws.phar`Not all services are immediately available in the SDK. To find out which services are
      currently supported by the AWS SDK for PHP, see [Service Name
         and API Version](https://docs.aws.amazon.com/aws-sdk-php/v3/api/index.html). 

###### Note

If you’re migrating your code from using Version 2 of the SDK to Version 3, be sure to
         read [Upgrading from Version 2 of the
            AWS SDK for PHP](./getting-started_migration.html).

## Get started with the SDK

      If you’re ready to get hands-on with the SDK, follow the [Getting started with the AWS SDK for PHP Version 3](./getting-started_index.html) chapter.
         It guides you through authentication with AWS, setting up your development environment,
         and creating your first basic application using Amazon S3.
