# Viewing the users that an analysis is shared with - Amazon Quick

**Source:** [https://docs.aws.amazon.com/quick/latest/userguide/view-users-analysis.html](https://docs.aws.amazon.com/quick/latest/userguide/view-users-analysis.html)

---

If you have shared an analysis, you can use the following procedure to see which users or groups have access to it.

###### To view which users or groups have access to an analysis

- 
	Open the [Quick console](https://quicksight.aws.amazon.com/).
- 
                    Open the analysis that you want to change. 
- 
                    On the analysis page, choose **File**on the application bar, and then choose**Share**.
- 
                    Choose **Manage analysis permissions**.
- 
                    Review who this analysis has been shared with. You can search to locate a specific account by typing a search term. The search returns any user, group, or email address that contains the search term. Searching is case-sensitive, and wildcards are not supported. Delete the search term to view all users and groups.
