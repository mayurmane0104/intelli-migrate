[Try it Yourself »](trymysql.asp?filename=trysql_func_mysql_degrees)

## Definition and Usage

The DEGREES() function converts a value in radians to degrees.

**Note:** See also the [RADIANS()](func_mysql_radians.asp) and
[PI()](func_mysql_pi.asp) functions.

## Syntax

```
  DEGREES(
```
*number*)
## Parameter Values

| Parameter | Description | 
|---|---|
| number | Required. A numeric value |
