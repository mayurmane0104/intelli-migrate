# SQL ADD Keyword

## ADD

The `ADD` command is used to add a column in an 
existing table.

### Example[Get your own SQL Server](/sql/sql_server.asp)

Add an "Email" column to the "Customers" table:

```
  ALTER TABLE Customers
ADD Email varchar(255);
 
```
