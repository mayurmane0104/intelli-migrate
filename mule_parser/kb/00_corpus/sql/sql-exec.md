# SQL EXEC Keyword

## EXEC

The `EXEC` command is used to execute a stored procedure.

The following SQL executes a stored procedure named "SelectAllCustomers":

### Example[Get your own SQL Server](/sql/sql_server.asp)

```
  EXEC SelectAllCustomers;
 
```
