# MySQL LOCALTIMESTAMP() Function

### Example[Get your own SQL Server](/sql/sql_server.asp)

Return current date and time:

```
  SELECT 
  LOCALTIMESTAMP(); 
```
[Try it Yourself »](trymysql.asp?filename=trysql_func_mysql_localtimestamp)

## Definition and Usage

The LOCALTIMESTAMP() function returns the current date and time.

**Note:** The date and time is returned as "YYYY-MM-DD HH-MM-SS" 
(string) or as YYYYMMDDHHMMSS.uuuuuu (numeric).

## Syntax

```
  LOCALTIMESTAMP()
```
