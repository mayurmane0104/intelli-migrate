# MS Access TimeValue() Function

### Example[Get your own SQL Server](/sql/sql_server.asp)

Return a time based on the given string:

```
  SELECT TimeValue("17:15:38"); 
```
[Try it Yourself »](trysql.asp?filename=trysql_func_ms_timevalue&ss=-1)

## Definition and Usage

The TimeValue() function returns a time based on a string.

## Syntax

```
  TimeValue(
```
*string*)
## Parameter Values

| Parameter | Description | 
|---|---|
| string | Required. A string that represents a time (from 0:00:00 to 23:59:59) |

| Works in: | From Access 2000 |
