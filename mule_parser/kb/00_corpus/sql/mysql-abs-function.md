```

```
[Try it Yourself »](trymysql.asp?filename=trysql_func_mysql_abs)

## Definition and Usage

The ABS() function returns the absolute (positive) value of a number.

## Syntax

```
  ABS(
```
*number*)
## Parameter Values

| Parameter | Description | 
|---|---|
| number | Required. A numeric value |
