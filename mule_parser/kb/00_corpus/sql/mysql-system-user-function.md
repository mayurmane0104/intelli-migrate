# MySQL SYSTEM_USER() Function

### Example[Get your own SQL Server](/sql/sql_server.asp)

Return the current user name and host name for the MySQL connection:

```
  SELECT SYSTEM_USER(); 
```
[Try it Yourself »](trymysql.asp?filename=trysql_func_mysql_system_user)

## Definition and Usage

The SYSTEM_USER() function returns the current user name and host name for the MySQL connection.

**Note:** This function is equal to the
[SESSION_USER()](func_mysql_session_user.asp) function and the
[USER()](func_mysql_user.asp) function.

## Syntax

```
  SYSTEM_USER()
```
