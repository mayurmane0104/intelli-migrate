# MS Access Functions 

MS Access has many built-in functions.

This reference contains the string, numeric, and date functions in MS Access.

## MS Access String Functions

| Function | Description | 
|---|---|
| [Asc](func_msaccess_asc.asp) | Returns the ASCII value for the specific character | 
| [Chr](func_msaccess_chr.asp) | Returns the character for the specified ASCII number code | 
| [Concat with &](func_msaccess_concat.asp) | Adds two or more strings together | 
| [CurDir](func_msaccess_curdir.asp) | Returns the full path for a specified drive | 
| [Format](func_msaccess_format.asp) | Formats a value with the specified format | 
| [InStr](func_msaccess_instr.asp) | Gets the position of the first occurrence of a string in another | 
| [InstrRev](func_msaccess_instrrev.asp) | Gets the position of the first occurrence of a string in another, from the end of string | 
| [LCase](func_msaccess_lcase.asp) | Converts a string to lower-case | 
| [Left](func_msaccess_left.asp) | Extracts a number of characters from a string (starting from left) | 
| [Len](func_msaccess_len.asp) | Returns the length of a string | 
| [LTrim](func_msaccess_ltrim.asp) | Removes leading spaces from a string | 
| [Mid](func_msaccess_mid.asp) | Extracts some characters from a string (starting at any position) | 
| [Replace](func_msaccess_replace.asp) | Replaces a substring within a string, with another substring, a specified number of times | 
| [Right](func_msaccess_right.asp) | Extracts a number of characters from a string (starting from right) | 
| [RTrim](func_msaccess_rtrim.asp) | Removes trailing spaces from a string | 
| [Space](func_msaccess_space.asp) | Returns a string of the specified number of space characters | 
| [Split](func_msaccess_split.asp) | Splits a string into an array of substrings | 
| [Str](func_msaccess_str.asp) | Returns a number as string | 
| [StrComp](func_msaccess_strcomp.asp) | Compares two strings | 
| [StrConv](func_msaccess_strconv.asp) | Returns a converted string | 
| [StrReverse](func_msaccess_strreverse.asp) | Reverses a string and returns the result | 
| [Trim](func_msaccess_trim.asp) | Removes both leading and trailing spaces from a string | 
| [UCase](func_msaccess_ucase.asp) | Converts a string to upper-case |

## MS Access Date Functions

| Function | Description | 
|---|---|
| [Date](func_msaccess_date.asp) | Returns the current system date | 
| [DateAdd](func_msaccess_dateadd.asp) | Adds a time/date interval to a date and then returns the date | 
| [DateDiff](func_msaccess_datediff.asp) | Returns the difference between two dates | 
| [DatePart](func_msaccess_datepart.asp) | Returns a specified part of a date (as an integer) | 
| [DateSerial](func_msaccess_dateserial.asp) | Returns a date from the specified parts (year, month, and day values) | 
| [DateValue](func_msaccess_datevalue.asp) | Returns a date based on a string | 
| [Day](func_msaccess_day.asp) | Returns the day of the month for a given date | 
| [Format](func_msaccess_format_date.asp) | Formats a date value with the specified format | 
| [Hour](func_msaccess_hour.asp) | Returns the hour part of a time/datetime | 
| [Minute](func_msaccess_minute.asp) | Returns the minute part of a time/datetime | 
| [Month](func_msaccess_month.asp) | Returns the month part of a given date | 
| [MonthName](func_msaccess_monthname.asp) | Returns the name of the month based on a number | 
| [Now](func_msaccess_now.asp) | Returns the current date and time based on the computer's system date and time | 
| [Second](func_msaccess_second.asp) | Returns the seconds part of a time/datetime | 
| [Time](func_msaccess_time.asp) | Returns the current system time | 
| [TimeSerial](func_msaccess_timeserial.asp) | Returns a time from the specified parts (hour, minute, and second value) | 
| [TimeValue](func_msaccess_timevalue.asp) | Returns a time based on a string | 
| [Weekday](func_msaccess_weekday.asp) | Returns the weekday number for a given date | 
| [WeekdayName](func_msaccess_weekdayname.asp) | Returns the weekday name based on a number | 
| [Year](func_msaccess_year.asp) | Returns the year part of a given date |
