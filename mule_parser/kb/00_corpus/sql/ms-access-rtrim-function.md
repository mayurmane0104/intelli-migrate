
## Definition and Usage

The RTrim() function removes trailing spaces from a string.

**Note:** See also the [LTrim()](func_msaccess_ltrim.asp) function.

## Syntax

```
  RTrim(
```
*string*)

| Parameter | Description | 
|---|---|
