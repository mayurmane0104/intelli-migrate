## Definition and Usage

The ATN2() function returns the arc tangent of two numbers.

## Syntax

```
ATN2(
```
*a, b*)
## Parameter Values

| Parameter | Description | 
|---|---|
| a, b | Required. Two numeric values to calculate the arc tangent of |
