# SQL Server PI() Function

## Definition and Usage

The PI() function returns the value of PI.

**Note:** Also look at the [DEGREES()](func_sqlserver_degrees.asp) and 
[RADIANS()](func_sqlserver_radians.asp) functions.

## Syntax

```
  PI()
```
