## Definition and Usage

The SQRT() function returns the square root of a number.

## Syntax

```
  SQRT(
```
*number*)
## Parameter Values

| Parameter | Description | 
|---|---|
| number | Required. A number to calculate the square root of. Must be greater than 0 |
