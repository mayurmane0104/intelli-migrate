# SQL Server LOG10() Function

### Example[Get your own SQL Server](/sql/sql_server.asp)

Return the base-10 logarithm of 2:

```
  SELECT LOG10(2); 
```
[Try it Yourself »](trysqlserver.asp?filename=trysql_func_sqlserver_log10)

## Definition and Usage

The LOG10() function returns the natural logarithm of a number to base 10.

**Note:** Also look at the [LOG()](func_sqlserver_log.asp) function.

## Syntax

```
  LOG10(
```
*number*)
## Parameter Values

| Parameter | Description | 
|---|---|
| number | Required. A number greater than 0 | 

## Technical Details

| Works in: | SQL Server (starting with 2008), Azure SQL Database, Azure SQL Data Warehouse, Parallel Data Warehouse |
