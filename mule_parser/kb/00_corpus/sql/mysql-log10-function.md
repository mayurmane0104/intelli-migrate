# MySQL LOG10() Function

```

```
[Try it Yourself »](trymysql.asp?filename=trysql_func_mysql_log10)

## Definition and Usage

The LOG10() function returns the natural logarithm of a number to base-10.

**Note:** See also the [LOG()](func_mysql_log.asp) function.

## Syntax

```
  LOG10(
```
*number*)
## Parameter Values

| Parameter | Description | 
|---|---|
| number | A number greater than 0 |
