# MySQL MOD() Function

## Definition and Usage

The MOD() function returns the remainder of a number divided by another number.

## Syntax

```
  MOD(
```
*x*, *y*)
**OR:**

```
  
```
*x* MOD *y*
**OR:**

```
  
```
*x *% *y*
## Parameter Values

| Parameter | Description | 
|---|---|
| x | Required. A value that will be divided by y | 
| y | Required. The divisor |
