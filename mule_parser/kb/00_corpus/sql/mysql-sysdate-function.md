# MySQL SYSDATE() Function

### Example[Get your own SQL Server](/sql/sql_server.asp)

Return the current date and time:

```
  SELECT SYSDATE(); 
```
[Try it Yourself »](trymysql.asp?filename=trysql_func_mysql_sysdate)

## Definition and Usage

The SYSDATE() function returns the current date and time.

**Note:** The date and time is returned as "YYYY-MM-DD HH:MM:SS" 
(string) or as YYYYMMDDHHMMSS (numeric).

## Syntax

```
SYSDATE()
```
