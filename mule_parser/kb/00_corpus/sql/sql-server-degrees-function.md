[Try it Yourself »](trysqlserver.asp?filename=trysql_func_sqlserver_degrees)

## Definition and Usage

The DEGREES() function converts a value in radians to degrees.

**Note:** See also the [RADIANS()](func_sqlserver_radians.asp) and
[PI()](func_sqlserver_pi.asp) functions.

## Syntax

```
  DEGREES(
```
*number*)
## Parameter Values

| Parameter | Description | 
|---|---|
| number | Required. A numeric value |
