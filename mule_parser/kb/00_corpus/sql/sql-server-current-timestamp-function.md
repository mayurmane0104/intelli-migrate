# SQL Server CURRENT_TIMESTAMP Function

### Example[Get your own SQL Server](/sql/sql_server.asp)

Return the current date and time:

```
  SELECT 
  CURRENT_TIMESTAMP; 
```
[Try it Yourself »](trysqlserver.asp?filename=trysql_func_sqlserver_curr_timestamp)

## Definition and Usage

The CURRENT_TIMESTAMP function returns the current date and time, in a 'YYYY-MM-DD hh:mm:ss.mmm' format.

**Tip:** Also look at the [GETDATE()](func_sqlserver_getdate.asp) function.

## Syntax

```
  CURRENT_TIMESTAMP
```
