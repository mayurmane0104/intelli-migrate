# SQL DROP VIEW Keyword

## DROP VIEW

The `DROP VIEW` command deletes a view.

The following SQL drops the "Brazil Customers" view:

### Example[Get your own SQL Server](/sql/sql_server.asp)

```
DROP VIEW [Brazil Customers]; 
```
