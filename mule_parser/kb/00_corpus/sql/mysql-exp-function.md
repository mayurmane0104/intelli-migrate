# MySQL EXP() Function

## Definition and Usage

The EXP() function returns *e* raised to the power of the specified 
number.

The constant *e* (2.718281...), is the base of natural logarithms.

**Tip:** Also look at the [LOG()](func_mysql_log.asp) and
[LN()](func_mysql_ln.asp) functions.

## Syntax

```
  EXP(
```
*number*)
## Parameter Values

| Parameter | Description | 
|---|---|
| number | Required. The power number |
