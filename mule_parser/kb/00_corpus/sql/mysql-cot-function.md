# MySQL COT() Function

## Definition and Usage

The COT() function returns the cotangent of a number.

## Syntax

```
  COT(
```
*number*)
## Parameter Values

| Parameter | Description | 
|---|---|
| number | Required. A numeric value. If number is 0, an error or NULL is returned | 

## Technical Details

| Works in: | From MySQL 4.0 |
