# MySQL CURRENT_TIMESTAMP() Function

### Example[Get your own SQL Server](/sql/sql_server.asp)

Return the current date and time:

```
  SELECT CURRENT_TIMESTAMP(); 
```
[Try it Yourself »](trymysql.asp?filename=trysql_func_mysql_current_timestamp)

## Definition and Usage

The CURRENT_TIMESTAMP() function returns the current date and time.

**Note:** The date and time is returned as "YYYY-MM-DD HH-MM-SS" 
(string) or as YYYYMMDDHHMMSS.uuuuuu (numeric).

## Syntax

```
CURRENT_TIMESTAMP()
```
