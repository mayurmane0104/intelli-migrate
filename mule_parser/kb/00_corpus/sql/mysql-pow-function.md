# MySQL POW() Function

Return 4 raised to the second power:

```
  SELECT POW(4, 2); 
```
[Try it Yourself »](trymysql.asp?filename=trysql_func_mysql_pow)

## Definition and Usage

The POW() function returns the value of a number raised to the power of another number.

**Note:** This function is equal to the
[POWER()](func_mysql_power.asp) function.

## Syntax

```
  POW(
```
*x*, y)
## Parameter Values

| Parameter | Description | 
|---|---|
| x | Required. A number (the base) | 
| y | Required. A number (the exponent) |
