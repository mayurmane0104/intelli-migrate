# MySQL CURTIME() Function

## Definition and Usage

The CURTIME() function returns the current time.

**Note:** The time is returned as 
"HH-MM-SS" (string) or as HHMMSS.uuuuuu (numeric).

**Note:** This function equals the [CURRENT_TIME()](func_mysql_current_time.asp) 
function.

## Syntax

```
CURTIME()
```
