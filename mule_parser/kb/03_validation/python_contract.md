# Python Lambda Contract

## 1. Handler Signature

```python
def handler(event: dict, context) -> dict:
    ...
```

**Rules**:
- Function must be named `handler` (configurable but `handler` is default)
- First param: `event` — always `dict` for JSON-based triggers
- Second param: `context` — `aws_lambda_powertools.utilities.typing.LambdaContext` or untyped
- Return type depends on trigger (see §2)

## 2. Return Types by Trigger

| Trigger | Return Type | Example |
|---|---|---|
| API Gateway HTTP API | `dict` with `statusCode`, `body` | See §2.1 |
| API Gateway REST API | Same as HTTP API | |
| SQS | `dict` with `batchItemFailures` | See §2.2 |
| EventBridge / Scheduler | `None` or any | Not inspected |
| Step Functions Task | Any JSON-serializable | Passed as state output |
| S3 Event | `None` | Not inspected |
| MSK (Kafka) | `None` | Not inspected |
| Direct Invoke | Any JSON-serializable | Returned to caller |

### 2.1 API Gateway Response
```python
return {
    "statusCode": 200,
    "headers": {"Content-Type": "application/json"},
    "body": json.dumps({"message": "ok", "data": result}),
}
```

### 2.2 SQS Partial Batch Failure
```python
return {
    "batchItemFailures": [
        {"itemIdentifier": record["messageId"]}
        for record in failed_records
    ]
}
```

## 4. Logger Initialization

```python
import logging

logger = logging.getLogger(__name__)
logger.setLevel(os.environ.get("LOG_LEVEL", "INFO"))
```

Never use `print()`. Always use `logger.info/warning/error`.

## 5. Environment Variable Naming

| Category | Pattern | Example |
|---|---|---|
| AWS resource IDs | `{SERVICE}_{RESOURCE}_NAME` or `_ARN` | `SQS_QUEUE_URL`, `SNS_TOPIC_ARN` |
| Database host | `DB_HOST`, `DB_PORT`, `DB_NAME` | |
| Secrets | `{PURPOSE}_SECRET_ARN` | `DB_PASSWORD_SECRET_ARN` |
| S3 | `S3_{PURPOSE}_BUCKET` | `S3_OUTPUT_BUCKET` |
| DynamoDB | `DYNAMODB_{PURPOSE}_TABLE` | `DYNAMODB_STATE_TABLE` |
| Feature flags | `FF_{NAME}` | `FF_ENABLE_RETRY` |
| Regions | `{SERVICE}_REGION` | `SES_REGION` |
| Log level | `LOG_LEVEL` | `INFO` |

**Rules**:
- Always SCREAMING_SNAKE_CASE
- Never abbreviate ambiguously (`Q_URL` → `SQS_QUEUE_URL`)
- All secret values must be ARNs pointing to Secrets Manager

## 6. Cold Start Caching Pattern

```python
# Module-level cache — lives for Lambda container lifetime
_boto3_clients: dict[str, Any] = {}
_db_connection = None
_secrets_cache: dict[str, Any] = {}


def get_client(service: str):
    if service not in _boto3_clients:
        _boto3_clients[service] = boto3.client(service)
    return _boto3_clients[service]


def get_secret(secret_arn: str) -> dict:
    if secret_arn not in _secrets_cache:
        sm = get_client('secretsmanager')
        resp = sm.get_secret_value(SecretId=secret_arn)
        _secrets_cache[secret_arn] = json.loads(resp['SecretString'])
    return _secrets_cache[secret_arn]
```

- `requests` (use `urllib3`)
- `flask` or `django` (not for Lambda handlers)
- `numpy`/`pandas` for simple transforms (too heavy; use list comprehensions)

## 8. Full Lambda Template

```python
"""
Lambda: <function_purpose>
Flow origin: <mule_app>/<flow_name>
Migration type: <batch_simple|batch_complex|api|event_driven|scheduler>
Generated by: Migration Studio
"""
from __future__ import annotations

import json
import logging
import os
from typing import Any

import boto3

logger = logging.getLogger(__name__)
logger.setLevel(os.environ.get("LOG_LEVEL", "INFO"))

# ── Cold-start cache ──────────────────────────────────────────────────────────
_clients: dict[str, Any] = {}


def _client(service: str):
    if service not in _clients:
        _clients[service] = boto3.client(service)
    return _clients[service]


# ── Business logic ────────────────────────────────────────────────────────────
def process(payload: dict, vars: dict | None = None) -> dict:
    """Core logic — pure function, no side effects, easily unit-testable."""
    if vars is None:
        vars = {}
    # TODO: implement
    return payload


# ── Handler ───────────────────────────────────────────────────────────────────
def handler(event: dict, context) -> dict:
    logger.info("Invocation started", extra={"event_keys": list(event.keys())})

    try:
        result = process(event)
        logger.info("Invocation succeeded")
        return {"statusCode": 200, "body": json.dumps(result)}

    except ValueError as e:
        logger.error("Validation error: %s", e)
        return {"statusCode": 400, "body": json.dumps({"error": str(e)})}

    except Exception as e:
        logger.exception("Unhandled error")
        raise   # Re-raise so Lambda marks invocation as error → retry/DLQ
```

## 9. Forbidden Patterns

```python
# ❌ Global mutable state across invocations
results = []

def handler(event, context):
    results.append(event)   # Accumulates across invocations — WRONG

# ❌ Hardcoded region
boto3.client('s3', region_name='us-east-1')   # Use env var or default

# ❌ Catching and swallowing all exceptions
try:
    risky()
except:
    pass   # Silent failure — WRONG

# ❌ Returning non-JSON-serializable types
return datetime.now()   # Not serializable — return .isoformat() string

# ❌ os.system() or subprocess for business logic
os.system("curl http://api.example.com")   # WRONG — use urllib3

# ❌ Writing to filesystem outside /tmp
open('/var/data/output.json', 'w')   # WRONG — only /tmp is writable
```

## 10. Unit Test Contract

Every Lambda module must have a corresponding `test_<module>.py`:

```python
import pytest
from unittest.mock import patch, MagicMock
import json

# Import the module under test
import lambda_function as fn


def test_process_happy_path():
    payload = {"key": "value"}
    result = fn.process(payload)
    assert "key" in result


def test_handler_returns_200():
    event = {"key": "value"}
    context = MagicMock()
    with patch.object(fn, '_client') as mock_client:
        response = fn.handler(event, context)
    assert response["statusCode"] == 200


def test_handler_validation_error():
    event = {}   # missing required field
    context = MagicMock()
    response = fn.handler(event, context)
    assert response["statusCode"] == 400
```
